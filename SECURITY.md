# Security policy

This is an early-stage design and pre-pilot project. No released product or support commitment is implied.

## Reporting a vulnerability

Please report suspected vulnerabilities privately using this repository's GitHub **Report a vulnerability** feature (Security tab → Advisories → Report a vulnerability). Do not open a public issue for an unpatched vulnerability.

Reports are handled on a best-effort basis. There is no service-level agreement or guaranteed response time. Please include the affected location, conditions needed to reproduce the issue, and any potential impact. Avoid including secrets or other people's personal data.
