# Support

This repository is a design and pre-pilot project. It does not currently make product support or response-time commitments.

For project questions or proposed improvements, use [GitHub Discussions](https://github.com/flair-agency/architecture-decision-authoring/discussions) if enabled, or open an [issue](https://github.com/flair-agency/architecture-decision-authoring/issues). Requests are considered on a best-effort basis, with no service-level agreement or guaranteed response time.

For security concerns, follow [SECURITY.md](SECURITY.md) and use private vulnerability reporting rather than a public issue.
